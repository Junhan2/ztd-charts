# 차트 카탈로그: 33종을 고른 이유

[English](catalog.md) · 한국어

> 사람이 아니라 차트가 말하게. 강조 하나, 한 줄 요약, 나머지는 조용히.

## 어떻게 골랐나

보고서와 대시보드에서 강조 하나로 잘 읽히고, 다크 카드 위에서도 또렷한 형태를 골랐어요. 모든 차트가 같은 카드를 써요. 번호, 제목, 회색 부제, 작은 네모 범례, 강조 하나, 굵은 한 줄 요약, 수준 배지예요.

기준은 두 가지예요.

1. **강조 하나로 메시지가 서는가.** 회색 다수 + 강조색 하나 방식에서 무너지는 차트(여러 색이 꼭 필요한 차트)는 뺐어요.
2. **등장 애니메이션이 의미를 더하는가.** 쓸어 그리기(파이), 바닥에서 차오르기(막대, 영역), 왼쪽에서 오른쪽으로 흐르기(생키, 선), 칸 채우기(와플, 캘린더)처럼 움직임이 읽는 순서를 알려주는 차트를 골랐어요.

## 넣지 않은 것, 합친 것

| 후보 | 결정 | 이유 |
|---|---|---|
| 폴라 에어리어 (나이팅게일) | 뺌 | 반지름으로 값을 나타내 넓이가 제곱으로 커져요. 예쁘지만 같은 자리를 레이더(지표 비교), 방사형 막대(달성률), 캘린더(계절성)가 더 정확히 채워요. |
| 진행률 고리 | 게이지로 합침 | 고리 하나짜리 진행률은 `GaugeChart variant="ring"`이에요. 여러 개면 방사형 막대예요. |
| 박스와 바이올린 | 하나로 합침 | 데이터 모양이 같아서 `BoxPlot variant="box" \| "violin" \| "both"`로 골라요. |
| 묶은, 쌓은, 100% 막대 | 하나로 합침 | `BarChart layout="grouped" \| "stacked" \| "percent"`, `orientation="horizontal"`. |
| 산점도 | 버블로 합침 | `BubbleChart`에서 size를 빼면 산점도예요. 스펙 별칭 `scatter`도 받아요. |
| 3D, 도넛 여러 겹, 게이지 바늘 | 뺌 | 읽기 어렵거나 장식에 가까워요. |
| 지도(코로플레스) | 이번엔 뺌 | 지도 데이터(TopoJSON)와 투영이 필요해 "의존성 0" 원칙과 충돌해요. 다음 후보예요. |

## 데이터가 많을 때

| 차트 | 방식 | 1만 점 결과 (QA 리포트 참고) |
|---|---|---|
| 라인, 영역, 스파크라인 | LTTB로 폭의 2배 점까지 줄여 path 하나 | 모양 유지, 호버는 원본 x 기준 |
| 버블(산점도) | 1,500개 넘으면 캔버스 + 격자 색인 근접 검색 | 축과 라벨은 SVG 그대로 |
| 히트맵 | 2,500칸 넘으면 캔버스, 대각선 물결 등장 | 칸 호버는 좌표 계산 |
| 비스웜 | 2,000개 넘으면 캔버스 | 배치 알고리즘은 같아요 |
| 평행 좌표 | 1,500줄 넘으면 캔버스(한 path에 모아 그리기) | 가까운 줄 찾기는 O(n) |
| 캘린더 | 4,000일(약 11년)까지 SVG, 넘으면 캔버스. 여러 해는 연도별 줄 | 27년(1만 일)도 한 장에, 칸 호버는 좌표 계산 |
